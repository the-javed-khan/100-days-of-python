# Day 09 – Dictionaries

------------------------------------------------------

## Part 01 – Dictionary Basics & Grading Program

### What I Fixed / Learned in Practice
- Dictionaries store data as key-value pairs.
- Keys are used to retrieve values.
- Dictionaries can be modified after creation.
- Looping through a dictionary returns keys by default.
- Values can be accessed using dictionary[key].
- New dictionary entries can be created dynamically.
- Conditional logic can classify dictionary values.

------------------------------------------------------

## Part 02 – Nested Data Structures

### What I Fixed / Learned in Practice
- Lists can be nested inside dictionaries.
- Lists can contain other lists.
- Dictionaries can contain nested dictionaries.
- Accessing nested data requires chaining keys and indexes.
- Dictionaries use keys, not indexes.
- KeyErrors occur when accessing non-existent keys.
- Correct way to update dictionaries: dict[key] = value.
